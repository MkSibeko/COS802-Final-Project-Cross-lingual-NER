# Presentation

`19144832_Sibeko_COS802_Presentation.pptx` is the 7-slide talk (about 7 minutes, with speaker notes). It is generated from the course template by `build_deck.py`:

```bash
python presentation/build_deck.py
```

- Needs `python-pptx` and `Pillow`. It reads the COS802 course template (not included in this repository; place it at `docs/course/COS802 2025 Presentation Template.pptx`) and the headshot from `assets/headshot.jpg`.
- Every number comes from `results/main_results_RQ1-RQ4.md` and matches the report.
- Colour code used throughout: Nguni blue, Sotho-Tswana orange, other Bantu green, same-language comparison grey.
